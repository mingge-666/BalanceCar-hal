# BalanceCar-hal
基于hal库的平衡小车

注意：由于编码的问题，再把标准可的oled_data的代码移植过程中，汉字的编译无法通过，不过在这个项目中不需要汉字，对本项目没有影响。
由于个人学习进度和目标，此处并没有加入蓝牙串口模块，只有角度环，速度环和转向环。（后面可能会加上，看时间是否充裕）
由于不同的硬件可能pid的各个参数会不一样，如果对这个代码有质疑的话也欢迎留言，后面可以加一下联系方式交流，我也可以把我的平衡车拍的视频发出来。也可以在我的能力范围内给予一些帮助。

此处hal库的代码对比标准库的优点：模块化更加强，如果还需要代码移植的话，代码的适应力会更强。而且结构更加清晰。具体的代码结构如下。

## 硬件平台（与标准库的相同）

| 模块 | 型号/说明 |
|------|-----------|
| 主控 | STM32F103C8T6 |
| 姿态传感器 | MPU6050（六轴，I2C 接口，PB10=SCL，PB11=SDA） |
| 电机 | 直流减速电机（JGA25-370） |
| 电机驱动 | TB6612 / DRV8833（PWM + 方向控制） |
| 编码器 | TIM3（左轮，PA6/PA7）、TIM4（右轮，PB6/PB7） |
| OLED | 0.96 寸 I2C 显示屏（PB8=SCL，PB9=SDA） |
| 按键 | 4 个独立按键（KEY1~KEY4） |

## 软件架构

采用 **前后台系统（裸机）**，主循环负责按键扫描和 OLED 显示，SysTick （1ms执行一次）中断中执行核心控制任务。

### 代码结构
Core/

├── Inc/

│   ├── main.h

│   ├── gpio.h

│   ├── tim.h

│   └── ...

├── Src/

│   ├── main.c              // 主函数，初始化外设，主循环

│   ├── gpio.c              // GPIO 初始化（按键、OLED、电机方向引脚）

│   ├── tim.c               // TIM2（PWM）、TIM3/TIM4（编码器）初始化

│   ├── stm32f1xx_it.c      // 中断服务函数（SysTick 调度核心任务）

│   └── ...

└── ...
### 核心模块

| 文件 | 功能说明 |
|------|----------|
| `MPU6050.c` | MPU6050 驱动，基于软件模拟 I2C，读取加速度和陀螺仪原始数据 |
| `MyI2C.c` | 软件 I2C 底层驱动（GPIO 模拟时序） |
| `Encoder.c` | 编码器读取，获取左右轮速度增量 |
| `PWM.c` | 电机 PWM 输出和方向控制 |
| `PID.c` | 位置式 PID 控制器（支持积分限幅、输出限幅、死区补偿） |
| `Tasks.c` | 核心控制任务：姿态解算、角度环、速度环、转向环、OLED 显示 |
| `Key.c` | 按键扫描（带消抖） |
| `OLED.c` | OLED 显示驱动（江协科技开源库） |

### 控制流程
SysTick 中断（1ms）

├── Key_Tick()           // 按键扫描（20ms 消抖）

├── 每 10ms 执行一次：

│   ├── Get_Data()       // 读取 MPU6050，互补滤波解算姿态角

│   └── Angle_Task()     // 角度环 PID，输出 PWM 控制电机

└── 每 50ms 执行一次：

└── Position_Task()  // 速度环 + 转向环，串级控制
### 控制算法

采用 **串级 PID** 结构：
速度环（SpeedPID）→ 角度环（AnglePID）→ PWM 输出

转向环（TurnPID）→ 差速 PWM
| 控制环 | 输入 | 输出 | 作用 |
|--------|------|------|------|
| 角度环 | 姿态角（互补滤波） | 平均 PWM | 维持车身直立 |
| 速度环 | 编码器平均速度 | 角度环目标值 | 控制前进/后退速度 |
| 转向环 | 左右轮速度差 | 差速 PWM | 控制转向 |

### 按键功能

| 按键 | 功能 |
|------|------|
| KEY1 | 启动平衡（初始化 PID 并进入运行状态） |
| KEY2 | 停止（电机停转，退出运行状态） |

### 调参说明

PID 参数在 `Tasks.c` 中以结构体初始化方式定义，主要参数：

- **AnglePID**：直立环，`Kp=5, Ki=0.1, Kd=5`
- **SpeedPID**：速度环，`Kp=2.5, Ki=0.07, Kd=0.05`
- **TurnPID**：转向环，`Kp=4, Ki=3, Kd=0`

OLED 实时显示三个控制环的 P/I/D 误差、目标值、实际值和输出值，方便现场调参。

## 使用说明

1. 建议使用 STM32CubeMX 生成工程（或直接打开 Keil 工程）
2. 编译下载到 STM32F103
3. 上电后 OLED 显示P、I、D各项的值，以及各个环的输出等
4. 按 KEY1 启动平衡，按 KEY2 停止
5. 通过 OLED 观察 PID 输出，调整参数至稳定
